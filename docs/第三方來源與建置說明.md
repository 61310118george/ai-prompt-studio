# 第三方來源與建置說明

本專題本機架構使用 Python、SQLite、pywebview、PyObjC 與 tiktoken；保留的舊入口使用 PySide6，打包使用 PyInstaller。各套件授權以安裝包的 LICENSE／METADATA 為準，對外發布前应整理所有隨包依賴的授權通知。本文不是完成授權審核的聲明。

Tokenizer 資料由 `scripts/prepare_tokenizers.py` 於建置時透過 tiktoken 的官方 encoding 來源準備，存於 `resources/tokenizers/`。App 執行時直接建立 Encoding，不用網路下載資料。JSON 內含來源網址；套件版本可由開發環境的 `pip show tiktoken` 查核。本次測試使用 tiktoken 0.14.0。

參考來源：[tiktoken repository](https://github.com/openai/tiktoken)、[pywebview](https://pywebview.flowrl.com/)、[SQLite](https://www.sqlite.org/)、[PyInstaller](https://pyinstaller.org/)。

正常執行：`.venv/bin/python run_app.py`。測試：`PYTHONPATH=src .venv/bin/python -m pytest -q`。打包：`bash scripts/build_macos_app.sh`。唯讀封裝診斷：`dist/AI Prompt Studio Next.app/Contents/MacOS/AI Prompt Studio Next --self-test`（路徑有空白時需加引號）。

瀏覽器 UI 測試使用獨立 Playwright／Chrome profile，macOS bridge 測試使用臨時 SQLite 與專案資料夾；不操作使用者真實提示詞。前者為 browser mock 流程，後者為真實 Python bridge 流程，兩者證據分開保存。
