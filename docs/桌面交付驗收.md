# 桌面版交付與驗收

版本日期：2026-09-26。

## 交付物

- App：`dist/AI Prompt Studio Next.app`，macOS Apple Silicon 本機測試版。
- 分發壓縮檔：`deliverables/AI Prompt Studio Next.zip`；排除 Finder 額外中繼資料，以免同步服務重新附加屬性影響簽章檢查。
- 可閱讀及列印企劃書：`deliverables/專題企劃書.html`。
- 可閱讀及列印 Spec：`deliverables/軟體規格書.html`。
- 正式 PDF 企劃書：`output/pdf/AI提示詞視覺化管理App_完整企劃書.pdf`，含五張操作介面與用途說明。
- 正式 PDF Spec：`output/pdf/AI提示詞視覺化管理App_軟體需求規格書.pdf`，含五張畫面規格與驗收重點。
- 可編輯文件原稿：`docs/專題企劃書.md`、`docs/SPEC.md`。

App 直接包入最終 HTML、CSS、JavaScript，以及 Python、SQLite 服務與本機 tokenizer 資料。不是遠端網站捷徑，也不需要使用者另外啟動 Web 伺服器。瀏覽器示範版仍使用 mock 資料，真實檔案與資料庫功能由桌面 bridge 提供。

## 可重現檢查

1. `.venv/bin/python -m pytest -q`：23 項測試，包含離線 Token 計數、版本衝突、舊資料保留、路徑限制、外部變更與精確復原。
2. `scripts/smoke_web.cjs`：瀏覽器建立與保存版本、分析、搜尋、重新載入；1440 與 390 寬度無橫向溢出或 JavaScript 錯誤。
3. `scripts/smoke_desktop.py`：原始碼桌面殼使用真實 WebKit 與 Python bridge，在暫存專案保存兩版、Token 分析、檔案匯出及復原。資料夾選擇以測試替身完成，因此不代表人工原生對話框驗收。
4. App 執行檔 `--self-test`：確認打包前端、四個 Agent 及兩種 tokenizer 可讀取。
5. `codesign --verify --deep --strict`：驗證本機 ad-hoc 簽章完整性，不等同 Apple Developer ID 簽署或公證。
6. 企劃書與 Spec PDF 均為 A4、11 頁，已逐頁轉成 PNG 檢查封面、目錄、表格、五張介面、頁首頁尾與中文字型；文字抽取無替代字元。

測試證據位於 `docs/evidence/`。未將原有資料庫搬入測試，未取代其他位置的舊 App。
